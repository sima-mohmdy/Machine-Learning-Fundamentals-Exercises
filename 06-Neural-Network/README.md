
# Perceptron and MNIST Digit Classification

## Overview

This folder contains two exercises focused on fundamental concepts of artificial neural networks, covering both implementing a simple Perceptron from scratch and applying a Multilayer Perceptron to handwritten digit classification.

## Exercises

### 1. Perceptron

Implement a Perceptron from scratch using NumPy and evaluate two learning methods: the Perceptron Learning Rule and the Delta Rule.

The Iris dataset is used to perform three binary classification tasks, comparing different pairs of flower species and investigating their linear separability.

**Main Topics:**
- Perceptron implementation from scratch
- Perceptron Learning Rule and Delta Rule
- Binary classification
- Activation functions and weight updates
- Linear separability

### 2. MNIST Digit Classification

Build a handwritten digit classification model using the MNIST dataset and scikit-learn's `MLPClassifier`.

The dataset contains 28 × 28 grayscale images represented by 784 pixel features. The task involves preprocessing the images, training a neural network, evaluating its performance, and predicting digit labels for the test set.

**Main Topics:**
- MNIST dataset and image visualization
- Data preprocessing and pixel normalization
- Multilayer Perceptron (MLP)
- Neural network classification
- Train-validation split and model evaluation
- Multiclass classification

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Learning Objectives

- Understand the fundamentals of Perceptrons and neural networks.
- Implement a basic learning algorithm from scratch.
- Compare different Perceptron learning rules.
- Apply a neural network to a practical image classification problem.
- Gain experience in preprocessing data and evaluating classification models.
